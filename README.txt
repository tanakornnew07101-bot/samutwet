สมุดเวท (แอปติดตั้งได้)
=======================

ไฟล์ในโฟลเดอร์นี้คือเว็บแอปทั้งชุด ต้องนำไปวางบนเว็บที่เป็น https ก่อน จึงจะติดตั้งเป็นแอปบนมือถือได้
(เปิดไฟล์ index.html ตรงๆ จากเครื่องจะใช้ได้ แต่ติดตั้งเป็นแอปและใช้ออฟไลน์ไม่ได้)

ไฟล์
- index.html            ตัวแอป
- manifest.webmanifest  ข้อมูลแอป (ชื่อ ไอคอน เปิดเต็มจอ)
- sw.js                 ให้เปิดใช้ตอนไม่มีเน็ตได้
- icon-*.png, apple-touch-icon.png  ไอคอน

ขั้นที่ 1 วางบนเว็บ (เลือกแบบใดแบบหนึ่ง ฟรีทั้งคู่ ปุ่มและเมนูอาจต่างจากที่เขียนเล็กน้อย)

  แบบ GitHub Pages
  1. สร้างบัญชี GitHub แล้วสร้าง repository ใหม่ (ตั้งเป็น Public)
  2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ระดับบนสุดของ repository (ไม่ต้องอยู่ในโฟลเดอร์ย่อย)
  3. ไปที่ Settings > Pages เลือก Deploy from a branch เลือก branch main โฟลเดอร์ / (root) แล้วกด Save
  4. รอสักครู่ จะได้ลิงก์รูปแบบ https://ชื่อผู้ใช้.github.io/ชื่อ-repository/

  แบบ Netlify
  1. สร้างบัญชี Netlify
  2. เลือกสร้างเว็บไซต์ใหม่แบบลากโฟลเดอร์ไปวาง (Add new site > Deploy manually)
  3. ลากโฟลเดอร์นี้ไปวาง จะได้ลิงก์ https ทันที

ขั้นที่ 2 ติดตั้งบนมือถือ
- Android (Chrome): เปิดลิงก์ แล้วเลือกเมนู ⋮ > ติดตั้งแอป (Install app) หรือเพิ่มไปยังหน้าจอหลัก
- iPhone (Safari เท่านั้น): เปิดลิงก์ กดปุ่มแชร์ แล้วเลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
เปิดจากไอคอนที่ได้ จะเปิดเต็มจอเหมือนแอป

ข้อควรรู้
- ข้อมูลเก็บในเครื่องที่ใช้อย่างเดียว ไม่ซิงก์ข้ามเครื่อง และไม่ซิงก์กับเวอร์ชันบน Claude
- ที่ท้ายหน้ามีปุ่ม "ส่งออกข้อมูลเป็นไฟล์" ควรกดเก็บไว้เป็นระยะ และก่อนเปลี่ยนเครื่อง
  ถ้าเปลี่ยนเครื่องหรือลบแอป ให้ใช้ "นำเข้าข้อมูลจากไฟล์" เพื่อกู้คืน
- บน iPhone แอปที่ติดตั้งจากหน้าจอโฮมกับหน้าเว็บใน Safari เก็บข้อมูลแยกกัน ให้ใช้จากไอคอนอย่างเดียว
- ครั้งแรกที่เปิดต้องมีอินเทอร์เน็ต เพื่อโหลดไฟล์และฟอนต์ หลังจากนั้นเปิดตอนออฟไลน์ได้
  (ถ้าฟอนต์ยังไม่ถูกเก็บ จะใช้ฟอนต์ของเครื่องแทนชั่วคราว)

การอัปเดตแอป
เมื่อมีไฟล์เวอร์ชันใหม่ ให้อัปโหลดทับไฟล์เดิม และเปลี่ยนเลขใน sw.js บรรทัด var CACHE = 'samutwet-v1'
เป็นเลขถัดไป (เช่น samutwet-v2) เครื่องที่ติดตั้งไว้จะได้ไฟล์ใหม่เมื่อเปิดแอปครั้งถัดไป
